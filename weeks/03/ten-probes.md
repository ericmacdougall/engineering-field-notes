# Ten probes before choosing the control surface

These are **proposed experiments**, not reported outcomes. Keep business authority and any consequential side effect in an isolated test environment with an owner-labeled expected result.

1. Give Jev `Choice` a refund case whose right next action is absent from the options. Add `needs_evidence`, rerun and inspect the action path. A typed answer alone must not authorize money movement.
2. Match Jev → writer → verification against a constrained small-model route on the same customer cases. Measure accepted answers, total latency, cost and reviewer minutes, including fallback.
3. Perturb irrelevant state and date wording in owner-labeled cases; record changes in decision and calibration without treating model confidence as policy.
4. Force malformed output under prompt-only, parse-and-retry, and grammar/mask controls where supported; separately test semantic counterexamples that remain syntactically valid.
5. Send a harmless denied tool request through each actual agent/runtime route, including delegated and external-provider paths; verify the hook receipt and absence of side effect.
6. Change a tool registry or permission after route selection but before dispatch; require a stale proposal to fail at the final host-owned check.
7. Resume a session with a pinned provider and verify automatic selection does not silently reroute it. Read back the actual executed provider.
8. Have a specialist role inject a small, versioned context packet containing one historical exception that retrieval misses. Expire or alter the packet and require a protected test to catch the omission.
9. Increase agent output in a small team simulation and measure accepted work, review queue age, rework and owner attention; stop when throughput stops improving.
10. For any proposed local open-weight deployment, calculate total weight memory plus cache/overhead and run a representative end-to-end benchmark on the exact machine. Distinguish active parameters from total stored weights.

Related primary sources and limits are linked in the [weekly article](https://ericmacdougall.com/journal/where-model-control-actually-lives/) when it is live. Do not replace measurements with a model-vendor headline.
